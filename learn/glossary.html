Glossary

Terms you can search

108 short entries. Search matches the term and the definition. Nothing is sent off this page.

ABCDEFGHIJLMNOPRSTUVW

No term matches that search. Try a shorter word, such as token, tool, or recall.

A

Activation

The value a neural-network unit emits after a function such as GELU, or a probability after softmax. People also say “activations” for the block of numbers leaving a layer.

See also Logit, Softmax

Agent

A control loop around a model: choose an action, carry it out, record the result, and stop under an explicit rule. A single completion with no later observation is not this loop.

See also ReAct, Stop condition, Tool

Approximate nearest neighbor (ANN)

A search that returns vectors close to a query without comparing the query to every stored vector. The speed comes with a recall tradeoff you should measure against an exact scan.

See also HNSW, Vector search, Recall at k

Attention

A transformer operation that rebuilds each token as a weighted mix of other tokens. The weights come from learned comparisons among those tokens (Vaswani et al., 2017).

See also Self-attention, Transformer, Context window

B

Beam search

A decoding method that keeps several partial sequences and expands the most promising ones. Chat systems more often use greedy decoding or sampling. Beam search remains a standard algorithm in sequence generation.

See also Greedy decoding, Sampling, Decoding

Bi-encoder

An embedding layout that encodes the query and the document separately, so document vectors can be stored before the query arrives.

See also Cross-encoder, Embedding, Dense retrieval

BM25

A lexical ranking function that scores term frequency, inverse document frequency, and document length. The probabilistic account is given by Robertson and Zaragoza (2009).

See also Sparse retrieval, Hybrid search, Lexical search

Byte-pair encoding (BPE)

A subword method that repeatedly merges the most frequent adjacent pair of symbols. Sennrich, Haddow, and Birch (2016) introduced it for rare words. Byte-level BPE, used by GPT-2 (Radford et al., 2019), merges bytes so any UTF-8 string can be tokenized.

See also Tokenization, SentencePiece, WordPiece

C

Chunk

A passage cut from a larger document so it can be embedded, indexed, and returned on its own.

See also Chunk overlap, Ingestion, Retrieval-augmented generation (RAG)

Chunk overlap

A repeated slice of text at the edges of neighboring chunks, so a sentence split by a boundary still appears whole in one chunk. Overlap costs tokens. It does not make a claim true.

See also Chunk, Retrieval-augmented generation (RAG), Token budget

Citation

A pointer from a claim to the passage that is supposed to support it. In a RAG system the pointer should identify retrieved text. A person or a grader still has to confirm the support.

See also Grounding, Retrieval-augmented generation (RAG), Hallucination

Completion

The tokens a model generates for a prompt. Older interfaces used this word for a single continuation.

See also Prompt, Decoding, Token

Context stuffing

Placing source text directly in the prompt instead of retrieving it from an index. Reasonable when the sources fit and stay few. Still depends on the model using that text.

See also Context window, Retrieval-augmented generation (RAG), Lost in the middle

Context window

The token budget for one request. Many APIs count input tokens and generated tokens against one limit. Read the model card for the accounting. The window is not the parameter count and not a long-term memory.

See also Token, Parameter, Lost in the middle

Cosine similarity

The cosine of the angle between two vectors. It ignores length. On L2-normalized vectors it ranks neighbors the same way as the dot product.

See also Dot product, Euclidean distance, Embedding

Cross-encoder

A model that scores a query and a passage together in one pass. A common reranker: stronger on a short list, too costly to run on a whole corpus.

See also Bi-encoder, Reranker, Retrieval-augmented generation (RAG)

D

Decoder-only model

A transformer that generates the next token from previous tokens only. Many chat models use this layout.

See also Encoder-decoder, Encoder-only model, Large language model (LLM)

Decoding

The rule that turns next-token probabilities into a sequence. Greedy decoding, beam search, and sampling are three families.

See also Greedy decoding, Sampling, Temperature

Dense retrieval

Retrieval by comparing learned vectors, as in Dense Passage Retrieval (Karpukhin et al., 2020), rather than by matching terms.

See also Sparse retrieval, Embedding, Bi-encoder

Deterministic decoding

A decoding setup that returns the same tokens for the same inputs, such as greedy decoding with a fixed model and prompt. Sampling with a random draw is not deterministic.

See also Greedy decoding, Sampling, Temperature

Detokenization

Mapping tokens back to text. The round trip can change whitespace relative to the original string.

See also Tokenization, Token, Special token

Direct preference optimization (DPO)

A preference-tuning method that updates a language model from chosen and rejected responses without a separate reinforcement-learning loop (Rafailov et al., 2023).

See also Preference optimization, RLHF, Instruction tuning

Dot product

The sum of coordinate-wise products of two vectors. If an embedding model was trained for dot-product search, query it that way.

See also Cosine similarity, Embedding, Vector

E

Embedding

A vector that represents an input so a chosen notion of similarity becomes a geometric comparison. It is not a readable summary and it is not a compressed file you can decode back into the paragraph.

See also Vector, Bi-encoder, Embedding drift

Embedding drift

A change in vectors for the same text after you switch or retrain the embedding model. Old and new vectors are not comparable. Rebuild the index.

See also Embedding, Index, Vector search

Encoder-decoder

A transformer layout with an encoder over the input and a decoder that generates the output. The original transformer and T5 use this shape.

See also Decoder-only model, Encoder-only model, Transformer

Encoder-only model

A transformer that represents a full input at once, as BERT does (Devlin et al., 2019). It is not, by itself, a left-to-right chat generator.

See also Decoder-only model, WordPiece, Embedding

Euclidean distance

Straight-line distance between two vectors. Some indexes use it instead of cosine similarity. Query with the metric you built for.

See also Cosine similarity, Vector search, Dot product

Evaluation

A repeatable measurement of a system against a written task, a fixed example set, and a rubric. A demo transcript is not an evaluation.

See also Golden set, Rubric, Regression test

Exact match

A score that passes only when the output equals a reference string under a stated normalization. Fair for short canonical answers. Harsh on a correct paraphrase.

See also Rubric, Evaluation, Grounding

F

Fine-tuning

Continued training that updates a model’s weights on a chosen dataset. Prompting does not do this.

See also Instruction tuning, Pretraining, Parameter

Foundation model

A model trained on broad data so it can be adapted to many downstream tasks. The term was set out in the Stanford report by Bommasani et al. (2021).

See also Large language model (LLM), Pretraining, Fine-tuning

Function calling

An interface where the model returns a structured request to run a named function. The application decides whether to run it.

See also Tool, Tool schema, JSON Schema

G

Golden set

A curated list of inputs with accepted outputs or grading notes, kept stable so scores can be compared over time.

See also Held-out set, Evaluation, Regression test

Greedy decoding

Choosing the single most likely next token at every step. As temperature approaches 0, sampling approaches this rule.

See also Decoding, Temperature, Deterministic decoding

Grounding

Requiring an answer to be supported by supplied sources, such as retrieved passages, rather than by an unsupported continuation.

See also Citation, Retrieval-augmented generation (RAG), Hallucination

Guardrail

A check around the model that blocks, edits, or escalates an input or an output. A guardrail is a control. It is not proof the model is safe.

See also Prompt injection, Human-in-the-loop, Refusal

H

Hallucination

Generated content that is not supported by the sources the task supplied, or that contradicts facts the task requires. Fluent grammar does not make it grounded. Creative writing is a different task and needs a different rubric.

See also Grounding, Citation, Evaluation

Held-out set

Examples you keep out of training and out of prompt tinkering, so a final check is not graded on items you already edited toward.

See also Golden set, Evaluation, Regression test

HNSW

Hierarchical Navigable Small World, a graph index for approximate nearest neighbor search (Malkov and Yashunin).

See also Approximate nearest neighbor (ANN), Vector search, Recall at k

Human-in-the-loop

A design where a person approves, edits, or grades a step before the system continues. Especially important before a side effect.

See also Side effect, Stop condition, Guardrail

Hybrid search

Retrieval that combines lexical scores, such as BM25, with dense vector scores.

See also BM25, Dense retrieval, Retrieval-augmented generation (RAG)

I

Idempotent operation

An operation that can be repeated without a further effect beyond the first success. Retries of a charge, a send, or a delete need this property on purpose. A stored idempotency key is one way to build it.

See also Side effect, Tool, Agent

Index

The stored structure used to look chunks up. It may hold vectors, term postings, metadata, and the original text.

See also Ingestion, Vector search, BM25

Ingestion

The pipeline that accepts source documents, records source and permission, and prepares them for chunking and indexing.

See also Chunk, Index, Retrieval-augmented generation (RAG)

Instruction tuning

Supervised training on examples of instructions and desired responses. It updates weights so following a request becomes more likely.

See also Fine-tuning, Pretraining, Prompt

Inverted file (IVF)

An approximate-search layout that partitions vectors into lists and searches only some lists. The name refers to those inverted lists of vector ids.

See also Approximate nearest neighbor (ANN), Product quantization, Vector search

J

JSON Schema

A vocabulary for describing the shape of JSON data: fields, types, and which fields are required. Tool definitions use it so a host can reject a call that does not match. The schema does not run the tool.

See also Tool schema, Function calling, JSON-RPC 2.0

JSON-RPC 2.0

A remote procedure call format whose messages are JSON objects with fields such as jsonrpc, method, params, and id. Specified by the JSON-RPC Working Group. It is not an IETF RFC. The Model Context Protocol uses it as the message envelope.

See also Model Context Protocol (MCP), Tool, MCP server

L

Large language model (LLM)

A language model with enough capacity to attempt many tasks, commonly implemented as a transformer trained to predict tokens.

See also Transformer, Token, Foundation model

Latency

The time from a request to a result. For a tool loop, add model time and tool time. Report a distribution, such as a median, not a single happy-path sample.

See also Evaluation, Token budget, Agent

Lexical search

Retrieval based on the terms actually present, as opposed to dense vectors. BM25 is the usual ranking function.

See also BM25, Sparse retrieval, Hybrid search

LLM-as-judge

Using a language model to score outputs against a rubric. Useful at scale, and unreliable until you compare it with human grades. Judges often prefer longer answers.

See also Rubric, Evaluation, Golden set

Logit

A raw score from the model for a token, before softmax turns the vector of scores into probabilities. Temperature divides logits.

See also Softmax, Temperature, Decoding

Loop budget

A hard cap on agent steps, tool calls, tokens, time, or money. Hitting the cap is a stop condition.

See also Stop condition, Agent, Token budget

Lost in the middle

A long-context failure mode reported by Liu et al. (2023): in the models they tested, relevant text in the middle of a long prompt was used less reliably than text at the ends. A finding, not a promise about every future model.

See also Context window, Retrieval-augmented generation (RAG), Grounding

M

MCP client

The connector inside a host that maintains one session with one MCP server.

See also MCP host, MCP server, Model Context Protocol (MCP)

MCP host

The application a person uses. It creates MCP clients and decides which advertised tools may actually run.

See also Model Context Protocol (MCP), MCP client, Human-in-the-loop

MCP prompt

A templated message exposed by an MCP server so a host can offer it to the user or the model. It is not a tool call and it is not a resource read.

See also Model Context Protocol (MCP), Prompt, Tool

MCP resource

Readable data exposed by an MCP server and addressed so the host can fetch it. Reading a resource is a different permission from invoking a tool.

See also Model Context Protocol (MCP), Tool, MCP server

MCP server

A program that offers tools, resources, or prompts through the Model Context Protocol. Its advertisement is not an allow-list. The host still chooses.

See also Model Context Protocol (MCP), Tool, MCP resource

Mean reciprocal rank (MRR)

The average, over queries, of 1 divided by the rank of the first relevant result. Rank 1 contributes 1. Rank 2 contributes 1/2. A miss contributes 0.

See also nDCG, Precision at k, Recall at k

Metadata filter

A constraint on fields such as source, date, or permission, applied so retrieval does not return a row the query is not allowed to see.

See also Retrieval-augmented generation (RAG), Index, Ingestion

Model Context Protocol (MCP)

An open protocol for connecting a host application to servers that expose tools, resources, and prompts. Messages follow JSON-RPC 2.0. Connecting a server is a trust decision.

See also MCP host, MCP server, JSON-RPC 2.0

N

nDCG

Normalized discounted cumulative gain. A ranking metric that rewards relevant items and gives more credit when they appear earlier.

See also Mean reciprocal rank (MRR), Precision at k, Recall at k

Nucleus sampling (top-p)

Sampling from the smallest set of tokens whose probabilities sum to at least p (Holtzman et al., 2020).

See also Top-k sampling, Temperature, Sampling

O

Observation

The tool result or other feedback written back into the agent context, including errors and empty results, so the next decision can use it.

See also Agent, Tool, Stop condition

P

Parameter

A learned weight stored in the model. Parameter count is not the context window and not the vocabulary size.

See also Weight, Fine-tuning, Context window

Perplexity

The exponentiated average negative log-likelihood of a token sequence. Lower perplexity means the model assigned the text higher probability. It is not a measure of truth or of retrieval quality.

See also Logit, Evaluation, Large language model (LLM)

Precision at k

Among the k retrieved items, the fraction that are relevant.

See also Recall at k, Mean reciprocal rank (MRR), nDCG

Preference optimization

Training that uses comparisons between a better response and a worse one. RLHF and DPO are two published forms.

See also RLHF, Direct preference optimization (DPO), Instruction tuning

Pretraining

The large first training pass, usually next-token prediction on a broad corpus, before instruction or preference tuning.

See also Instruction tuning, Fine-tuning, Parameter

Product quantization

A compression method that splits a vector into subvectors and replaces each with the id of a nearby centroid (Jégou, Douze, and Schmid, 2011).

See also Approximate nearest neighbor (ANN), Vector search, Inverted file (IVF)

Prompt

The input tokens for a request: instructions, examples, and source text. A prompt does not change the model’s weights.

See also System prompt, Context window, Instruction tuning

Prompt injection

Instructions hidden in data — a user message, a retrieved document, or a tool result — that try to override the behavior the application intended. The OWASP Top 10 for Large Language Model Applications lists it as a primary risk.

See also Guardrail, Tool, Retrieval-augmented generation (RAG)

R

ReAct

A published agent pattern that alternates a reasoning note with an action in an environment (Yao et al., 2023).

See also Agent, Observation, Tool

Recall at k

Among the items marked relevant for a query, the fraction that appear in the top k results.

See also Precision at k, Mean reciprocal rank (MRR), Golden set

Refusal

A response that declines a request, from the model or from a policy around it. Evaluate both the cases that should be refused and the benign cases that should still be answered.

See also Guardrail, Evaluation, Prompt injection

Regression test

A repeated evaluation that fails when a change lowers a metric you intended to hold steady.

See also Golden set, Evaluation, Held-out set

Reranker

A second-stage scorer that reorders a short candidate list. A cross-encoder is a common implementation.

See also Cross-encoder, Top-k retrieval, Retrieval-augmented generation (RAG)

Retrieval-augmented generation (RAG)

A pattern that retrieves passages from a corpus and conditions the model’s answer on them (Lewis et al., 2020). Retrieval does not guarantee the model will follow the passages.

See also Chunk, Grounding, Citation

RLHF

Reinforcement learning from human feedback. The InstructGPT recipe trains from human comparisons of responses and then updates the model (Ouyang et al., 2022).

See also Direct preference optimization (DPO), Preference optimization, Instruction tuning

Rubric

The written criteria a grader, human or automated, uses to score an answer. A number without a rubric cannot be compared with another number.

See also Evaluation, LLM-as-judge, Exact match

S

Sampling

Drawing the next token from the model’s distribution, usually after temperature, top-k, or top-p has reshaped it. The same prompt can yield different text.

See also Temperature, Nucleus sampling (top-p), Greedy decoding

Self-attention

Attention in which the queries, keys, and values all come from the same sequence. It is the core block of the transformer (Vaswani et al., 2017).

See also Attention, Transformer, Decoder-only model

SentencePiece

A tokenization toolkit that learns subwords, including BPE and unigram language models, and can segment raw text without a separate word splitter (Kudo and Richardson, 2018).

See also Byte-pair encoding (BPE), Tokenization, WordPiece

Side effect

A tool result that changes something outside the conversation: writing, paying, deleting, or sending. Side effects need a stricter gate than lookups.

See also Idempotent operation, Human-in-the-loop, Tool

Softmax

The function that turns a vector of logits into positive numbers that sum to 1, so they can be used as probabilities.

See also Logit, Temperature, Sampling

Sparse retrieval

Retrieval from term overlap and term statistics, as in BM25, rather than from dense vectors.

See also BM25, Dense retrieval, Lexical search

Special token

A vocabulary entry with a control role, such as marking a boundary or a role. It still counts toward the context window.

See also Token, Vocabulary, Tokenization

Stop condition

The rule that ends an agent loop: the goal is met, a budget runs out, an error repeats, a person must approve, or the person cancels.

See also Loop budget, Agent, Human-in-the-loop

Subword

A vocabulary piece smaller than a whole word, so a rare word can be built from known pieces instead of becoming a single unknown token.

See also Byte-pair encoding (BPE), WordPiece, Tokenization

System prompt

Instructions the application places ahead of the user message to set role and constraints. They are still tokens in the context window, and prompt injection can target them.

See also Prompt, Prompt injection, Context window

T

Temperature

A positive divisor applied to logits before softmax. Lower values sharpen the distribution toward the most likely tokens. As it approaches 0, decoding approaches a greedy choice.

See also Softmax, Sampling, Greedy decoding

Token

The integer unit a given model reads and writes. The matching string may be a word, a piece of a word, punctuation, or bytes.

See also Tokenization, Vocabulary, Context window

Token budget

The number of tokens allocated to a prompt, a retrieval pack, a completion, or a whole loop. Budgets keep a request inside the context window and inside a cost cap.

See also Context window, Token, Loop budget

Tokenization

The conversion of text into tokens with one model’s vocabulary and algorithm. Do it with the tokenizer that belongs to the model you will call.

See also Token, Byte-pair encoding (BPE), Detokenization

Tool

A named operation the application can run at the model’s request, with a description and an argument schema. The model requests it. The host runs it, or refuses.

See also Tool schema, Function calling, Model Context Protocol (MCP)

Tool schema

The machine-readable declaration of a tool’s name, purpose, and arguments. The host should reject calls that do not match it, and should validate again inside the implementation.

See also JSON Schema, Tool, Function calling

Top-k retrieval

Returning the k highest-scoring chunks for a query. A larger k raises the chance the evidence is present and also the amount of distractor text.

See also Reranker, Recall at k, Retrieval-augmented generation (RAG)

Top-k sampling

Restricting the next-token draw to the k most likely tokens, then sampling inside that set.

See also Nucleus sampling (top-p), Sampling, Temperature

Transformer

The neural architecture introduced by Vaswani et al. in 2017, built from attention and position-wise feed-forward layers. Most large language models use it.

See also Attention, Large language model (LLM), Self-attention

U

UTF-8

A byte encoding of Unicode, specified in RFC 3629. Byte-level tokenizers consume those bytes. Strings that look the same can still differ in code points and then in tokens.

See also Tokenization, Byte-pair encoding (BPE), Token

V

Vector

An ordered list of numbers. An embedding is a vector. Comparing vectors requires an agreed metric.

See also Embedding, Cosine similarity, Vector search

Vector search

Finding stored vectors close to a query vector, either by an exact scan or by an approximate index such as HNSW.

See also Approximate nearest neighbor (ANN), Embedding, HNSW

Vocabulary

The finite set of tokens a model can read or emit. Text outside that set is built from pieces that are inside it.

See also Token, Special token, Byte-pair encoding (BPE)

W

Weight

A numeric parameter learned during training. At inference time the weights stay fixed unless a separate training job updates them.

See also Parameter, Fine-tuning, Pretraining

WordPiece

A subword tokenization method used by BERT (Devlin et al., 2019). Words are built from known pieces, with a marker on pieces that continue a word.

See also Byte-pair encoding (BPE), SentencePiece, Tokenization
